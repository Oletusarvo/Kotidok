# Kotidok

Kotidok is an application for modeling and documenting the lifecycle of properties.

Properties are represented through three core concepts:

- **Components** — the physical or logical parts of a property (e.g. roof, HVAC system, wiring).
- **Connections** — relationships between components (e.g. dependency, containment, flow).
- **Events** — time-based records related to components or connections (e.g. installation, maintenance, inspection, replacement).

Together, these create a structured, evolving model of a property.

## Purpose

The goal of Kotidok is to build a comprehensive and queryable picture of a property's **state** and **history**. This makes it easier to:

- Service and maintain properties
- Diagnose issues
- Document changes over time
- Increase transparency when selling or transferring ownership

Kotidok treats a property not as static documentation, but as a living system with structure and history.
